# Repository agent instructions

For initial setup or consolidation, follow [the layout guide](references/layout.md). Preserve existing guidance. If instructions are missing, draft them from the repository’s actual commands, conventions and constraints using [the writing guide](references/writing.md).

For a content edit, resolve the existing instruction file to its canonical target and make the requested change there. For a wider rewrite or cleanup, use the writing guide. If conflicting copies make the target ambiguous, flag the conflict before choosing where to write.
